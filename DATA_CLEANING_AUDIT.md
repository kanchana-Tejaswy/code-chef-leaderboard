## 3. Score Calculations and Formula Verification

### Exact `overallScore` Formula Used in Script
The script calculates the overall score by summing the weighted score of each linked platform profile, and then scaling that sum by dividing it by the sum of weights of the active platforms:

$$\text{overallScore} = \text{round}\left( \frac{\sum (\text{Platform Score} \times \text{Platform Weight})}{\sum \text{Weights of Active Platforms}} \right)$$

*   **Weights Used**:
    *   CodeChef: $0.35$
    *   LeetCode: $0.35$
    *   GitHub: $0.30$
*   **Platform Score Conversions**:
    *   `codechefScore` = $\text{round}(\text{currentRating} / 30)$ if profile is linked, else $0$.
    *   `leetcodeScore` = $\text{round}(\text{problemsSolved} / 10)$ if profile is linked, else $0$.
    *   `githubScore` = `openSourceScore` if profile is linked, else $0$.

### Score Changes and Discrepancies
*   **Comparison with Sync Service**: The formula used in `clean-ranking-data.ts` uses static mathematical conversions (e.g., dividing rating by 30 or problems solved by 10) to compute platform scores. In contrast, the standard `sync.service.ts` pulls these scores from the `ai_analysis` table (generated by the AI Engine).
*   **Result**: While this did not cause unexpected regressions, it means that during the manual run, the platform scores and the resulting `overallScore` were recalculated using the script's custom linear formulas rather than the AI engine's results.
